# Football on TV – project notes for Claude

A personal phone web app for George: what's on UK TV for **today + the next 7 days**, with **UK times** and the **UK TV channel**. It covers football (Premier League, Champions League, Europa League, Championship, and televised League Cup and FA Cup ties), Formula 1, Formula 2, televised PDC darts, golf (PGA Tour + DP World Tour), snooker (World Snooker Tour) and men's international cricket. Hosted on GitHub Pages (https://genanev.github.io/football-on-tv/) and added to George's phone (Pixel 9) home screen. `README.md` is the human-facing overview; this file holds the rules, details and conventions.

George is not a developer: explain anything he has to do in plain language. He's building it to learn and plans to commercialise it (Play Store later), so keep it close to how a commercial app would be built: data from the official ("golden") source wherever possible, one module per source, offline tests, each source failing independently.

## Principles (George's decisions – keep these)

- **No guessing (13 Oct 2026):** a channel is shown only when an official source confirms it (a broadcaster's TV guide or listings page, or the competition's own TV picks). Never infer a channel from who holds the rights. Without confirmation the event says "TV channel to be confirmed" (no pill). The one rule-based note is the Saturday 15:00 football blackout ("Not shown live on UK TV"), a broadcasting rule, not a guess.
- **Where channels come from (13 Oct 2026):** the Sky TV guide (Sky's EPG, covering every channel on Sky) is the main source. Cross-check it for missing bits against each broadcaster's own schedule pages: Sky Sports' "on Sky" pages (Sky Sports+ streams), TNT Sports' schedule (HBO Max streams) and Prime Video's Champions League page (Amazon's Tuesday pick, which George considers essential). Add other broadcasters' pages the same way when needed.
- **Keeping a channel (14 Oct 2026):** a channel once confirmed is kept only if the source that confirmed it failed on a later update, or the event has started (see "Keep rule").
- **Each source fails independently:** one source failing never breaks the others; the app shows a yellow banner for it.

## Architecture

- `scripts/build.mjs` (Node 24, ES modules, no dependencies) fetches every source in parallel (`Promise.allSettled`), matches events to channels and writes `data.json`: `{ generatedAt, windowDays, report, events[] }`. The window is UK midnight today + 9 days (`DAYS_AHEAD` = 8; the app shows 8 days).
  - Each event: `comp` (`PL`/`UCL`/`UEL`/`CHAMP`/`CUPS`/`F1`/`F2`/`DARTS`/`GOLF`/`SNOOKER`/`CRICKET`), `kind` (`match` for football, `session` for the rest), optional `label` (cup ties: "FA Cup"/"EFL Cup"), `kickoff` (ISO UTC), `source` (where the schedule came from) and `tv` (`broadcaster`, `channels`, `alsoOn`, `confirmed`, `note`, `sources`). Sessions also have `title`, `session`, `end`, `timeTbc`, `allDay`. Football matches have `home`, `away`, `status`, `homeScore`, `awayScore`.
  - `tv.sources` tags where a channel came from: `sky-guide`, `skysports.com`, `tntsports.co.uk`, `primevideo.com`, `thefa.com`, `premierleague.com`, `previous-update` (kept from the last update), `listings` (the old fan site, before 13 Oct 2026; never kept).
  - `report` has one entry per source with `ok` (plus counts/errors; `wrongRegion` for Prime Video's US page). It exits 1 and keeps the old `data.json` only if every fixture source failed.
- Source modules (`scripts/sources/`), one per source family:
  - Fixtures: `football.mjs` (PL, UCL, UEL; team-name matching `normTeam`/`teamSim`/`ALIASES`; `guideProgrammesFor` matches a match to TV-guide programmes), `efl.mjs` (Championship, League Cup), `facup.mjs`, `motorsport.mjs` (F1 + F2), `darts.mjs`, `golf.mjs`, `snooker.mjs`, `cricket.mjs`.
  - TV listings: `skyGuide.mjs` (Sky EPG, channel IDs per sport in `SPORT_CHANNELS`, and the shared helpers that turn guide programmes into sessions: `groupSessions`, `sessionLabel`, `nameScore`, `guideTv`, `windowDates`), `skyListings.mjs` (Sky Sports' pages), `tntSchedule.mjs`, `amazonPrime.mjs`.
  - `footballTv.mjs`: the channel for any football match (combines the TV sources; see "Channel rules").
  - Shared helpers: `scripts/lib/util.mjs` (UK time conversion: `ukToUtc`, `ukDate`, `ukMidnight`, `londonParts`; `getJSON`/`getText`).
- `.github/workflows/update.yml` runs the build every hour at :17 (GitHub often starts these late or skips them) and on demand (Actions → Update fixtures → Run workflow), then commits `data.json`. Each run commits because `generatedAt` changes, which also stops GitHub pausing the schedule.
- `.github/workflows/check.yml` runs on pushes to any branch except `main`: all offline tests, then a live build (not saved) that fails if any source didn't answer from GitHub's US servers (Prime Video's expected `wrongRegion` is only noted).
- `index.html` is the whole app (inline CSS/JS). On `*.github.io` it reads `data.json` from `raw.githubusercontent.com/<user>/<repo>/main/` (updates show within ~5 minutes), falling back to the local `data.json`. It reloads on open and when the tab becomes visible, and re-renders every minute. `?demo` loads `demo-data.json` (24 Sept 2026 week: F1, F2, darts) and `?demo=2` loads `demo-data-2.json` (12–20 Oct 2026: golf, snooker, cricket), pretending it's that week.
- `design-a.html` is **Design A**, a trial multi-sport redesign developed alongside `index.html` until George picks one: sport icons (My TV, Football, Motorsport, Golf, Cricket, Others, Specials), competition chips, and a customisable **My TV** default view. It reads the same `data.json`; `?demo=3` loads `preview-data.json` (real 17 Oct 2026 data plus made-up `sample: true` events for MotoGP and Specials). Full description in `designA.md`. It duplicates `index.html`'s listing and banner code, so changes to those go in both.

| PL broadcaster | `api.premierleague.com/broadcasting/match-events?sportDataId=<ids>`. Answers for the **requester's country by IP** (no query parameter overrides it). | UCL / UEL fixtures | `match.uefa.com/v5/matches?competitionId=<1 UCL, 14 UEL, 2019 Conference League>&fromDate=&toDate=` (kick-off times in real UTC, live scores). UEFA doesn't publish UK channels. |
| Championship, League Cup | EFL feed behind efl.com: `multi-club-matches.webapi.gc.eflservices.co.uk/v2/matches?from=<YYYY-MM-DD 00:00:00Z>&to=…&competitionID=2,10&seasonID=<YYYY>&page.size=100` (same platform as PDC/WST; competitions: 10 Championship, 11 League One, 12 League Two, 2 League Cup, 7 EFL Trophy, from `/v2/competitions`). `kickOffDateUTC` in UTC, `matchPeriod` (PreMatch/FirstHalf/…/FullTime), live scores. |
| FA Cup | thefa.com/competitions/thefacup/fixtures: server-rendered `table.gTable` per date (`.headl` date, `.headr` round; rows `.cOne` time (written `<time datetime=">12:30">`), `.cThree`/`.cFive` teams, `.cSeven` "Live on BBC Sport"). The FA's "Live on" column is the official TV pick; the page shows the next round's ties only. |

| F2 sessions | `api.formula1.com/v1/core-event-tracker/f2` with fiaformula2.com's public web key. Current or next weekend: `race.meetingSessions`. `sessionStatus: "TBC"` = provisional times. Meeting keys are shared with F1. |
| Darts | PDC feed behind pdc.tv: `tournaments.darts.web.gc.pdcservices.co.uk/v2/?seasonID=<YYYY>&page.size=300` (JSON:API style). `isTelevised` picks the TV events. It has **no session start times** (those are only in PDC news articles), so sessions come from the TV guide. `fixtures.darts.web…/v2/` has matches with actual start times after they're played. |
| Golf (PGA Tour) | `orchestrator.pgatour.com/graphql` with header `x-api-key` = pgatour.com's public web key; `schedule(tourCode:"R", year:"<YYYY>")` gives each event's `startDate` (ms, midnight UTC of round 1). Events are taken as Thu–Sun (4 days). |
| Golf (DP World Tour) | `www.europeantour.com/dpworld-tour/schedule/` (and `…/schedule/<next year>/`): the page's schema.org **JSON-LD** lists every event (`subEvent[]`: `name`, `StartDate`/`EndDate` = local midnight written in UTC, so +12h gives the local date). The site returns 403 unless the request has browser-style headers (`Sec-Fetch-*`). Majors and co-sanctioned events are on both tours and are merged (`sameEvent`). |
| Snooker | WST feed behind wst.tv: `tournaments.snooker.web.gc.wstservices.co.uk/v2/?season=<YYYY>` (same platform as the PDC feed; season 2026 = 2026/27). No "televised" flag, so the TV guide decides. Qualifiers are skipped. |
| Cricket | ICC feed behind icc-cricket.com: `assets-icc.sportz.io/cricket/v1/schedule?client_id=…&league_ids=1&from_date=&to_date=&timezone=0000` (men's internationals; times in GMT as `M/D/YYYY` + `HH:MM`). Kept: Tests, ODIs and T20Is between the 12 Full Members. In 2025–27 they ran in 71 of 78 weeks (gap: late March–April, IPL season). |
| UK TV guide | Sky EPG: `awk.epgsky.com/hawk/linear/schedule/<YYYYMMDD>/<sid,sid,…>`; channel list from `/hawk/linear/services/4101/1`. Covers all Sky-platform channels (Sky Sports, TNT 1–4, BBC, ITV, Channel 4/5) from **today to ~8 days ahead, no past days**. Live programmes have titles starting "Live" (not always: some placeholders like "India - T20 International Cricket" aren't labelled). Used for every competition. Football titles read "Live UEL: Lyon v Crystal Palace", "Live EFL: Stoke v Middlesbrough", "Live MNF: …". |
| Sky Sports listings | skysports.com/watch/`football-on-sky` and `f1-on-sky` (others exist: darts, golf, cricket, …; `sport-on-sky` = today+tomorrow, all sports). Each page lists a fixed number of upcoming events (football ≈ 5 days, F1 = next two race weekends), and drops a game once it has kicked off. Lists Sky Sports+ streams that aren't in the TV guide. |
| TNT Sports schedule | The data behind tntsports.co.uk/watch/schedule.shtml (the page itself returns 403 to scripts): `netsport.eurosport.io?operationName=programsByDateQuery&extensions={persistedQuery:{version:1,sha256Hash:<hash>}}&variables={after,date:<UK midnight as UTC ISO>,first:500}` with header `domain: www.tntsports.co.uk`. Each programme: `title` ("RB Salzburg - AC Milan"), `subtitle` ("UEFA Europa League \| League Phase"), `startTime`/`endTime`, `isLive`, `channel.name` ("TNT Sports 1"…, or bare "TNT Sports" = streamed only on HBO Max, shown as "HBO Max"). Covers 7 days back and 7 ahead. The hash is a fingerprint of TNT's website code: if TNT updates its site and requests fail, find the new one in the schedule page's network requests ("programsByDateQuery"). |
| Prime Video (Amazon's UCL pick) | primevideo.com/tournament/amzn1.dv.icid.f40b96cd-f09e-48db-a9ec-0b0e298a39c8 – the Champions League page; server-rendered `<article data-card-title="Liverpool vs. Villarreal" data-card-entity-type="EVENT">` cards with the start of coverage ("Tue, Oct 20 6:30 PM BST", "Tomorrow 7:45 PM BST") and the provider in the logo path `benefit-id/<x-y>/<Provider>/logos`: `Prime` = Amazon's own pick, `discoverytntuk` = TNT resold through Prime Video Channels. **Serves each country its own page** (from the US: ViX+/Paramount+ only). amazon.co.uk's own pages return 503 to scripts; primevideo.com doesn't. Finished games drop off (today's may still be listed without a date). |

The F1/F2/PGA Tour API keys (and the ICC client id) are the ones each website sends from every visitor's browser. If one starts returning 401, find the new one in the site's JavaScript (search for `apikey`).

## Channel rules

**Football (`footballTv`, every competition):** all confirmed channels from (1) live Sky-guide programmes on a football channel, on air at kick-off, naming both teams (`guideTeams` + `teamSim`; youth/women's games – "U19", "Women", "WSL" – are skipped), (2) Sky's "Football on Sky" page (`skyListingFor`: same UK date + both team names), (3) TNT's schedule (`tntProgrammesFor`: live, on air at kick-off, competition in the subtitle, both teams or one exactly) are combined, main channel first, HBO Max last. Else, for the UCL, Amazon's own pick on Prime Video (`primePickFor`: provider "Prime", both teams in the same order, same UK date if shown). Else, for the PL, the league's own broadcaster feed gives a brand ("Sky Sports"). Else Saturday 15:00 PL/Championship = "Not shown live on UK TV", else "TV channel to be confirmed".
- Listed: all PL, UCL, UEL and Championship matches. Cups tab: televised ties only – League Cup ties when in the guide or on Sky's page, FA Cup ties the FA marks "Live on …" (exact channel from the guide if listed, else the FA's wording, e.g. "BBC Sport").
- Champions/Europa League games show the broadcaster's team names (TNT's or Amazon's: "Manchester City v Paris Saint-Germain", "Atlético Madrid v Manchester United", not UEFA's "Man City v Paris", "Atleti v Man Utd").
- Team names are matched fuzzily (`normTeam`/`teamSim` and an `ALIASES` map: e.g. Atleti → Atlético Madrid, Paris → PSG, Spurs → Tottenham Hotspur). If a team fails to match a broadcaster's listing, add an alias.
- TNT's schedule lists TNT Sports 5–10 games as HBO Max streams; those channels aren't in Sky's guide.

**Motorsport:** practice sessions are skipped. A session's channel is confirmed when a live programme on Sky Sports F1 / Main Event / Sky Sports+ / Channel 4 covers its start and is about the same series (`seriesOf`). Otherwise Sky's "F1 on Sky" page (`sessionMatches`: "… GP - Qualifying 1" = Qualifying, "… GP - Race" = Race); otherwise "TV channel to be confirmed".

**Darts and snooker:** each live programme in the guide on a tournament day becomes a session (simulcasts and back-to-back parts on one channel merge; before 12:00 = "Morning session", before 17:00 = "Afternoon session", otherwise "Evening session"). A televised darts day with nothing in the guide shows one "TBC" entry with "TV times to be confirmed"; snooker and golf days are only listed when the guide shows them (or, if the guide is unavailable for that day, as "TBC").

**Golf:** one entry per tournament per day ("Round 1"…, "Day 1"… for the Ryder/Solheim Cup), from the first to the last live programme that names the tournament (`nameScore`) or its tour (`tourOf`: "PGA Tour", "DP World Tour"; LPGA/LIV programmes are ignored).

**Cricket:** England matches are always listed; other internationals only when a guide programme on a cricket channel is on air at the start of play, names a team and, if it has an ordinal ("4th T20"), matches the match number. Programmes not labelled "Live" must start close to play and name the team in the title. The main channel is one on air at the start; later ones are "also on". A Test has one entry per day ("2nd Test, Day 3"); tri-series games read "Match 2 (ODI)".

**Keep rule (`keepKnownChannels`):** every update reads the previous `data.json`. When this update finds no channel for an event that had one, the old channel is kept **only if** the source that confirmed it (`tv.sources` → report entry via `SOURCE_REPORT` in `build.mjs`) failed this time, or the event has already started (Sky's pages and Prime Video drop games once they kick off or finish; the event then stays until it leaves the window at the end of its UK day). If the source answered and simply no longer lists an event that hasn't started, the broadcaster dropped it: back to "TV channel to be confirmed". A newly confirmed channel always replaces the old one (e.g. Sky moving a game from Main Event to Premier League). Channels from the old fan site (`listings`) are never kept.

**Amazon stopgap (George chose option 1, 14 Oct 2026):** the hourly updates run on GitHub's US servers, which get Prime Video's US page. `fetchPrimeUcl` recognises a page with no "Prime" and no "…uk" providers as `wrongRegion` (a failure: no banner, and `check.yml` only notes it), so a pick found by an update run from the UK is kept by the keep rule until the end of the match day. Someone must run one update from a UK computer each week before Tuesday's games (`node scripts/build.mjs`, commit `data.json`, `git pull --rebase`, push). George has chosen option 2 – running the updates from a UK server – as the next step; it removes this stopgap and makes the PL broadcaster feed useful.

UK rights for 2026/27 (background only – never used to infer a channel): PL on Sky Sports and TNT Sports; UCL on TNT Sports plus Amazon Prime Video's Tuesday pick (Paramount+ takes over from 2027/28); F1/F2 on Sky Sports F1 (Channel 4: British GP live); PDC darts on Sky Sports, some events on ITV; golf on Sky Sports Golf; snooker on TNT Sports, the BBC (UK Championship, Masters, World Championship) and Channel 5 (Players Championship, Tour Championship, British Open); cricket on Sky Sports and TNT Sports.

## UI decisions George has made (keep these)

- Tabs, four rows: **All** (narrower) · **Premier League** · **Champions League**, then **EFL / FA Cups** · **Championship** · **Europa League** (Championship under PL, Europa League under UCL), then **Formula 1** · **Formula 2** · **Darts**, then **Golf** · **Snooker** · **Cricket**, full names. **All** shows everything. The rows share columns (CSS subgrid) so the tabs line up one under the other, split 28 / 44 / 28 (outer columns never narrower than their longest name). Tab text is 13px below 410px wide and 12px below 365px so the long names fit (checked 320–412px; Pixel 9 = 412px).
- Every day of the 8-day window is listed. An empty day says "No scheduled PL / UCL / UEL / Championship / Cups / F1 / F2 / Darts / Golf / Snooker / Cricket" under All, or "No scheduled PL games" / "No scheduled UCL games" / "No scheduled UEL games" / "No scheduled Championship games" / "No televised cup ties" / "No F1 sessions" / "No F2 sessions" / "No televised darts" / "No televised golf" / "No televised snooker" / "No international cricket on TV" when filtered.
- F1/F2: qualifying, sprint and race sessions only (no practice). Darts and snooker: TV events only, one entry per session. Golf: one entry per round on UK TV. Cricket: men's internationals between the 12 Full Members, England always, others only when on UK TV.
- Day/date headings are 16px, uppercase.
- Channel pills: TNT/HBO magenta, Amazon blue, **Sky Sports orange** (`#d35400`, not red), others grey. White text in light mode; dark text on lighter pills in dark mode. Competition labels are outlined in the competition's colour; cup ties show their cup ("FA Cup", "EFL Cup").
- Theme toggle shows **Light / Dark only** (no Auto). The first visit follows the phone's setting; after that the choice is saved in localStorage.
- No refresh button: the app reloads data on open and when you switch back to it.
- **A channel pill and a note never appear together:** a note only explains a missing channel ("Not shown live on UK TV", "TV channel to be confirmed", "TV times to be confirmed"). "…to be confirmed" notes are also hidden once an event has started (a LIVE NOW game showing "expected" looks wrong).
- Footer: only the two "Fixtures from… / Channels from…" sentences (keep them in step with the sources).
- All times are shown in Europe/London time.
- The live label reads **LIVE NOW** (one line, under the time). It follows the phone's clock for every sport (it compares exact moments, so it is right in any time zone): sessions between their start and end, football from kick-off to ~1h55 later; the feed's "live" can stretch that to at most 2h45 after kick-off (updates can be hours apart, so an old "live" must not stick; its stale score is hidden).
- Football scores stay on (13 Oct 2026): the PL, UEFA and EFL feeds give live scores; the app shows the score from the last update during a match and the final score at FT. They'll be near real time once updates run every few minutes.
- Yellow banners: one per failed source, only under the tabs it affects.
- The app name stays "Football on TV" for now (George will rename it later; `manifest.webmanifest`'s description still mentions only football).

## Working conventions

- **Branches:** new features go on a branch; pushing runs `check.yml` (tests + live check from GitHub's US servers – read the result via the GitHub API, `gh` isn't installed). George reviews (preview pane or screenshots) and merges only when he says so. Small doc/fix commits George asked for can go straight to `main`.
- **After merging to `main`:** run the four tests, push, and if data-affecting, run one update (`node scripts/build.mjs`), commit `data.json` ("Update fixtures") and push, so the change shows before the next (often late) hourly run. That run is also the UK run the Amazon stopgap needs.
- **Git:** there's no global git identity on George's PC – commit with `git -c user.name="George" -c user.email=<George's email from the session context>`; end messages with the Co-Authored-By trailer. The hourly bot also commits `data.json` to `main`, so `git pull --rebase` before pushing to `main` – that needs the identity too (`git -c user.name=… -c user.email=… pull --rebase`), or the rebase stops half-way.
- **Update workflow:** `update.yml` checks out `main` (not the triggering commit, so a "Re-run" of an old run uses current code) and, if its push is refused because something else was saved meanwhile, rebases with `-X theirs` (its `data.json` wins) and retries up to 3 times.
- **Code:** Node 24 ES modules, no npm dependencies. One module per source; every fetch in `build.mjs`'s `Promise.allSettled`; each source gets a `report` entry with `ok`. When adding a TV source: add its `tv.sources` tag to `SOURCE_REPORT` (keep rule), a banner in `index.html` (only for the tabs it affects), the footer, and the data-source table above. Comments explain *why* (source quirks), matching the existing style.
- **Editing files on this Windows machine:** working copies have CRLF line endings (`core.autocrlf=true`). Scripted multi-line edits must normalise `\r\n` first. Never build JavaScript source through a shell heredoc or template string containing backslashes (a `\b` once became a literal backspace character in a regex) – use the Write/Edit tools, then check for stray control characters.
- **Requests:** some sites need browser-style headers (`Sec-Fetch-*` for europeantour.com, amazon.co.uk refuses scripts entirely). Node's `fetch` can be treated differently from `curl` – verify with Node.
