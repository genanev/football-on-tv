# Football on TV – project notes for Claude

A personal phone web app for George: what's on UK TV for **today + the next 7 days**, with **UK times** and the **UK TV channel**. It covers football (Premier League, Champions League, Europa League, Championship, and televised League Cup and FA Cup ties), Formula 1, Formula 2, televised PDC darts, golf (PGA Tour + DP World Tour), snooker (World Snooker Tour) and men's international cricket. It's hosted on GitHub Pages and added to his phone's home screen. Keep the app simple; George is not a developer, so explain any steps he has to do on GitHub in plain language. He is building it to learn, so keep it close to how a commercial app would be built: data from the official ("golden") source wherever possible, one module per source, offline tests, and each source failing independently.

**No guessing (George, 13 Oct 2026):** a channel is shown only when an official source confirms it (a broadcaster's TV guide or listings page, or the competition's own TV picks). Never infer a channel from who holds the rights. Without confirmation the event says "TV channel to be confirmed" (no pill). The one rule-based note kept is the Saturday 15:00 football blackout ("Not shown live on UK TV"), which is a broadcasting rule, not a guess.

**Where channels come from (George, 13 Oct 2026):** the Sky TV guide (Sky's EPG for its subscribers, covering every channel on Sky) is the main source. Cross-check it for missing bits against each broadcaster's own schedule pages: Sky Sports' "on Sky" pages (Sky Sports+ streams) and TNT Sports' schedule (HBO Max streams). Add other broadcasters' pages the same way when needed.

## How it works

- `scripts/build.mjs` (Node 24, no dependencies) fetches everything and writes `data.json`: `{ generatedAt, windowDays, report, events[] }`. Each event has `comp` (`PL`/`UCL`/`UEL`/`CHAMP`/`CUPS`/`F1`/`F2`/`DARTS`/`GOLF`/`SNOOKER`/`CRICKET`), `kind` (`match` for football, `session` for the rest), optional `label` (cup ties: "FA Cup"/"EFL Cup"), `kickoff` (ISO UTC), `source` (where the schedule came from) and `tv` (`broadcaster`, `channels`, `alsoOn`, `confirmed`, `note`, `sources`). Sessions also have `title`, `session`, `end`, `timeTbc`, `allDay`. `report` has one entry per source with `ok`.
- Source modules: `scripts/sources/football.mjs` (PL, UCL, UEL fixtures, team-name matching, `guideProgrammesFor` – matching a match to TV-guide programmes), `footballTv.mjs` (the channel for any football match: Sky guide + Sky Sports page + TNT schedule + the PL's own broadcaster feed), `efl.mjs` (Championship, League Cup), `facup.mjs`, `motorsport.mjs` (F1 + F2), `darts.mjs`, `golf.mjs`, `snooker.mjs`, `cricket.mjs`, `skyGuide.mjs` (UK TV guide, plus the shared helpers that turn guide programmes into sessions), `skyListings.mjs` (Sky Sports' own "what's on" pages), `tntSchedule.mjs` (TNT Sports' own schedule). Shared helpers in `scripts/lib/util.mjs`.
- `.github/workflows/update.yml` runs the build every hour (GitHub often starts these late or skips some) and on demand from the Actions tab, then commits `data.json`. Each run commits because `generatedAt` changes, which also stops GitHub pausing the schedule for inactivity.
- `.github/workflows/check.yml` runs on pushes to any branch except `main`: all offline tests, then a live build (not saved) that fails if any source didn't answer from GitHub's US servers.
- `index.html` is the whole app (inline CSS/JS). On `*.github.io` it reads `data.json` from `raw.githubusercontent.com/<user>/<repo>/main/` so updates show within minutes, and falls back to the local `data.json`. `?demo` loads `demo-data.json` (a recorded week with F1, F2 and darts) and pretends it's that week; `?demo=2` loads `demo-data-2.json` (12–20 Oct 2026: golf, snooker, cricket).
- Tests (run after any change to the build): `node test/run-test.mjs` (Premier League + Champions League and the shared time/name helpers: real data captured 13 Oct 2026; `--write-sample` rewrites `data.json` from the fixtures – don't commit that over live data) and `node test/run-sports-test.mjs` (F1/F2/darts, real data captured 12 Oct 2026 for the Baku weekend 24–26 Sept and the World Grand Prix darts; `--write-demo` rewrites `demo-data.json`) and `node test/run-golf-snooker-cricket-test.mjs` (real data captured 12 Oct 2026 for 12–20 Oct, including the real Sky guide; `--write-demo` rewrites `demo-data-2.json`) and `node test/run-more-football-test.mjs` (Europa League, Championship, cups: real data captured 13 Oct 2026). Fixtures are in `test/fixtures/`.

## Data sources (all unofficial, undocumented endpoints)

| What | Source |
|---|---|
| PL fixtures | `sdp-prem-prod.premier-league-prod.pulselive.com/api/v2/matches?competition=8&season=<YYYY>&matchweek=<n>`; current matchweek from `resources.premierleague.com/premierleague25/config/current-gameweek.json`. `kickoff` is UK local time, labelled by `kickoffTimezone` (BST/GMT). |
| PL broadcaster | `api.premierleague.com/broadcasting/match-events?sportDataId=<ids>`. Answers for the **requester's country by IP** (no query parameter overrides it). GitHub runners are in the US, so it returns NBC/Peacock etc.; `isUkChannel()` keeps only channels whose `restrictedCountries` include `GB`. In practice it adds nothing when run on GitHub. |
| UCL / UEL fixtures | `match.uefa.com/v5/matches?competitionId=<1 UCL, 14 UEL, 2019 Conference League>&fromDate=&toDate=` (kick-off times in real UTC, live scores). UEFA doesn't publish UK channels. |
| Championship, League Cup | EFL feed behind efl.com: `multi-club-matches.webapi.gc.eflservices.co.uk/v2/matches?from=<YYYY-MM-DD 00:00:00Z>&to=…&competitionID=2,10&seasonID=<YYYY>&page.size=100` (same platform as PDC/WST; competitions: 10 Championship, 11 League One, 12 League Two, 2 League Cup, 7 EFL Trophy, from `/v2/competitions`). `kickOffDateUTC` in UTC, `matchPeriod` (PreMatch/FirstHalf/…/FullTime), live scores. |
| FA Cup | thefa.com/competitions/thefacup/fixtures: server-rendered `table.gTable` per date (`.headl` date, `.headr` round; rows `.cOne` time (written `<time datetime=">12:30">`), `.cThree`/`.cFive` teams, `.cSeven` "Live on BBC Sport"). The FA's "Live on" column is the official TV pick; the page shows the next round's ties only. |
| F1 sessions | `api.formula1.com/v1/event-tracker` with header `apikey` = formula1.com's public web key. Returns the **current or next** weekend only: `seasonContext.timetables` (local `startTime` + `gmtOffset`) and `race`. `/v1/event-tracker/meeting/<meetingKey>` gives any weekend (used to capture test data). |
| F2 sessions | `api.formula1.com/v1/core-event-tracker/f2` with fiaformula2.com's public web key. Current or next weekend: `race.meetingSessions`. `sessionStatus: "TBC"` = provisional times. Meeting keys are shared with F1. |
| Darts | PDC feed behind pdc.tv: `tournaments.darts.web.gc.pdcservices.co.uk/v2/?seasonID=<YYYY>&page.size=300` (JSON:API style). `isTelevised` picks the TV events. It has **no session start times** (those are only in PDC news articles), so sessions come from the TV guide. `fixtures.darts.web…/v2/` has matches with actual start times after they're played. |
| Golf (PGA Tour) | `orchestrator.pgatour.com/graphql` with header `x-api-key` = pgatour.com's public web key; `schedule(tourCode:"R", year:"<YYYY>")` gives each event's `startDate` (ms, midnight UTC of round 1). Events are taken as Thu–Sun (4 days). |
| Golf (DP World Tour) | `www.europeantour.com/dpworld-tour/schedule/` (and `…/schedule/<next year>/`): the page's schema.org **JSON-LD** lists every event (`subEvent[]`: `name`, `StartDate`/`EndDate` = local midnight written in UTC, so +12h gives the local date). The site returns 403 unless the request has browser-style headers (`Sec-Fetch-*`). Majors and co-sanctioned events are on both tours and are merged (`sameEvent`). |
| Snooker | WST feed behind wst.tv: `tournaments.snooker.web.gc.wstservices.co.uk/v2/?season=<YYYY>` (same platform as the PDC feed; season 2026 = 2026/27). No "televised" flag, so the TV guide decides. Qualifiers are skipped. |
| Cricket | ICC feed behind icc-cricket.com: `assets-icc.sportz.io/cricket/v1/schedule?client_id=…&league_ids=1&from_date=&to_date=&timezone=0000` (men's internationals; times in GMT as `M/D/YYYY` + `HH:MM`). Kept: Tests, ODIs and T20Is between the 12 Full Members. In 2025–27 they ran in 71 of 78 weeks (gap: late March–April, IPL season). |
| Sky Sports listings | skysports.com/watch/`football-on-sky` and `f1-on-sky` (others exist: darts, golf, cricket, …; `sport-on-sky` = today+tomorrow, all sports). Server-rendered: `h3.text-h4` day ("Wed 14th October", no year), `div.event-group` with `<strong>` team names (or one title, e.g. "United States GP - Qualifying 1") and `p.event-detail` caption "Championship, Sky Sports+ (19:45)" (competition, then each channel with its start time). Each page lists a fixed number of upcoming events (football ≈ 5 days, F1 = next two race weekends), and drops a game once it has kicked off. Lists Sky Sports+ streams that aren't in the TV guide. |
| TNT Sports schedule | The data behind tntsports.co.uk/watch/schedule.shtml (the page itself returns 403 to scripts): `netsport.eurosport.io?operationName=programsByDateQuery&extensions={persistedQuery:{version:1,sha256Hash:<hash>}}&variables={after,date:<UK midnight as UTC ISO>,first:500}` with header `domain: www.tntsports.co.uk`. Each programme: `title` ("RB Salzburg - AC Milan"), `subtitle` ("UEFA Europa League \| League Phase"), `startTime`/`endTime`, `isLive`, `channel.name` ("TNT Sports 1"…, or bare "TNT Sports" = streamed only on HBO Max, shown as "HBO Max"). Covers 7 days back and 7 ahead. The hash is a fingerprint of TNT's website code: if TNT updates its site and requests fail, find the new one in the schedule page's network requests ("programsByDateQuery"). |
| UK TV guide | Sky EPG: `awk.epgsky.com/hawk/linear/schedule/<YYYYMMDD>/<sid,sid,…>`; channel list from `/hawk/linear/services/4101/1`. Covers all Sky-platform channels (Sky Sports, TNT, BBC, ITV, Channel 4) from **today to ~8 days ahead, no past days**. Live programmes have titles starting "Live" (not always: some placeholders like "India - T20 International Cricket" aren't labelled). Used for every competition. Football titles read "Live UEL: Lyon v Crystal Palace", "Live EFL: Stoke v Middlesbrough", "Live MNF: …". |

The F1/F2/PGA Tour API keys (and the ICC client id) are the ones each website sends from every visitor's browser. If one starts returning 401, find the new one in the site's JavaScript (search for `apikey`).

Every update reads the previous `data.json` and, when a source no longer gives an event a channel, keeps the channel it had (`keepKnownChannels`): Sky's pages drop a game once it has kicked off. Channels that came from the old fan site (`sources` includes "listings", before 13 Oct 2026) are never kept. The app hides "…to be confirmed" notes (incl. "Expected – To Be Confirmed") once an event has started (George: a LIVE NOW game showing "expected" looks wrong).

Football channels (`footballTv`, every competition): all confirmed channels from (1) live Sky-guide programmes on a football channel, on air at kick-off, naming both teams (`guideTeams` + `teamSim`; youth/women's games – "U19", "Women", "WSL" – are skipped), (2) Sky's "Football on Sky" page (`skyListingFor`: same UK date + both team names), (3) TNT's schedule (`tntProgrammesFor`: live, on air at kick-off, competition in the subtitle, both teams or one exactly) are combined, main channel first, HBO Max last. Else, for the PL, the league's own broadcaster feed gives a brand ("Sky Sports"). Else Saturday 15:00 PL/Championship = "Not shown live on UK TV", else "TV channel to be confirmed". Champions/Europa League games show TNT's team names when TNT lists them ("Manchester City v Paris Saint-Germain", not UEFA's "Man City v Paris"). All PL, UCL, UEL and Championship matches are listed. Cups tab: televised ties only – League Cup ties when in the guide or on Sky's page, FA Cup ties the FA marks "Live on …" (exact channel from the guide if listed, else the FA's wording, e.g. "BBC Sport").

Team names are matched fuzzily (`normTeam`/`teamSim` and an `ALIASES` map: e.g. Atleti → Atlético Madrid, Paris → PSG, Spurs → Tottenham Hotspur). If a team fails to match a broadcaster's listing, add an alias. Amazon Prime Video's Tuesday Champions League pick has no official machine-readable source (its store and news pages have no schedule), so it shows "TV channel to be confirmed". TNT's schedule lists TNT Sports 5–10 games as HBO Max streams; those channels aren't in Sky's guide.

Motorsport: practice sessions are skipped. A session's channel is confirmed when a live programme on Sky Sports F1 / Main Event / Sky Sports+ / Channel 4 covers its start and is about the same series (`seriesOf`). Otherwise Sky's "F1 on Sky" page (`sessionMatches`: "… GP - Qualifying 1" = Qualifying, "… GP - Race" = Race); otherwise "TV channel to be confirmed".

Darts and snooker: each live programme in the guide on a tournament day becomes a session (simulcasts and back-to-back parts on one channel merge; before 12:00 = "Morning session", before 17:00 = "Afternoon session", otherwise "Evening session"). A televised darts day with nothing in the guide shows one "TBC" entry with "TV times to be confirmed"; snooker and golf days are only listed when the guide shows them (or, if the guide is unavailable for that day, as "TBC").

Golf: one entry per tournament per day ("Round 1"…, "Day 1"… for the Ryder/Solheim Cup), from the first to the last live programme that names the tournament (`nameScore`) or its tour (`tourOf`: "PGA Tour", "DP World Tour"; LPGA/LIV programmes are ignored).

Cricket: England matches are always listed; other internationals only when a guide programme on a cricket channel is on air at the start of play, names a team and, if it has an ordinal ("4th T20"), matches the match number. Programmes not labelled "Live" must start close to play and name the team in the title. The main channel is one on air at the start; later ones are "also on". A Test has one entry per day ("2nd Test, Day 3"); tri-series games read "Match 2 (ODI)".

Rules: a Saturday 15:00 PL or Championship game with no channel gets "Not shown live on UK TV". Otherwise, a game with no channel shows "TV channel to be confirmed". UK rights for 2026/27: PL is on Sky Sports and TNT Sports. UCL is on TNT Sports, plus Amazon Prime Video for one Tuesday pick; Paramount+ takes over from 2027/28. F1 and F2 are on Sky Sports F1 (Channel 4 shows the British GP live). PDC darts is on Sky Sports, with some events on ITV. Golf: PGA Tour, DP World Tour and the majors on Sky Sports Golf. Snooker: TNT Sports (most events), the BBC (UK Championship, Masters, World Championship) and Channel 5 (Players Championship, Tour Championship, British Open). Cricket: Sky Sports (England, and many other series) and TNT Sports. Each source can fail independently; the app shows a yellow banner when it does.

## UI decisions George has made (keep these)

- Tabs, four rows: **All** (narrower) · **Premier League** · **Champions League**, then **EFL / FA Cups** · **Championship** · **Europa League** (Championship under PL, Europa League under UCL), then **Formula 1** · **Formula 2** · **Darts**, then **Golf** · **Snooker** · **Cricket**, full names. Tab text is 13px below 410px wide and 12px below 365px so the long names fit (checked 320–412px; George has a Pixel 9, 412px). **All** shows everything. The rows share columns so the tabs line up one under the other, split 28 / 44 / 28 (outer columns never narrower than their longest name).
- Every day of the 8-day window is listed. An empty day says "No scheduled PL / UCL / UEL / Championship / Cups / F1 / F2 / Darts / Golf / Snooker / Cricket" under All, or "No scheduled PL games" / "No scheduled UCL games" / "No scheduled UEL games" / "No scheduled Championship games" / "No televised cup ties" / "No F1 sessions" / "No F2 sessions" / "No televised darts" / "No televised golf" / "No televised snooker" / "No international cricket on TV" when filtered.
- F1/F2: qualifying, sprint and race sessions only (no practice). Darts and snooker: TV events only, one entry per session. Golf: one entry per round on UK TV. Cricket: men's internationals between the 12 Full Members, England always, others only when on UK TV.
- A future **Specials** section is planned for one-off events (e.g. Wimbledon, Tour de France); MotoGP/cycling could go there.
- Day/date headings are 16px, uppercase.
- Channel pills: TNT magenta, Amazon blue, **Sky Sports orange** (`#d35400`, not red). White text in light mode; dark text on lighter pills in dark mode.
- Theme toggle shows **Light / Dark only** (no Auto). The first visit follows the phone's setting; after that the choice is saved in localStorage.
- No refresh button: the app reloads data on open and when you switch back to it.
- **A channel pill and a note never appear together** (George's rule): a note only explains a missing channel ("Not shown live on UK TV", "TV channel to be confirmed", "TV times to be confirmed"). So "Expected – To Be Confirmed" / "Exact channel to be confirmed" are still written to `data.json` but never shown when a pill is. "…to be confirmed" notes are also hidden once an event has started.
- Footer: only the two "Fixtures from… / Channels from…" sentences.
- All times are shown in Europe/London time.
- The live label reads **LIVE NOW** (one line, under the time). It follows the phone's clock for every sport (it compares exact moments, so it is right in any time zone): sessions between their start and end, football from kick-off to ~1h55 later; the feed's "live" can stretch that to at most 2h45 after kick-off (updates can be hours apart, so an old "live" must not stick; its stale score is hidden).
- Football scores stay on (decided 13 Oct 2026, after seeing UCL scores update during matches): both the PL and UEFA feeds give live scores, so the app shows the score from the last update during a match and the final score at FT. They'll be near real time once updates run every few minutes (planned move to a proper platform).
