# Football on TV – project notes for Claude

A personal phone web app for George: what's on UK TV for **today + the next 7 days**, with **UK times** and the **UK TV channel**. It covers football (Premier League, Champions League, Europa League, Championship, Scottish Premiership, televised Conference League and WSL games, and televised League Cup and FA Cup ties), Formula 1, Formula 2, Formula 3, MotoGP, televised PDC darts, golf (PGA Tour + DP World Tour), snooker (World Snooker Tour) and men's international cricket. Hosted on GitHub Pages (https://genanev.github.io/football-on-tv/) and added to George's phone (Pixel 9) home screen. `README.md` is the human-facing overview; this file holds the rules, details and conventions.

George is not a developer: explain anything he has to do in plain language. He's building it to learn and plans to commercialise it (Play Store later), so keep it close to how a commercial app would be built: data from the official ("golden") source wherever possible (football fixtures and scores now come from API-Football, a paid data service, with the official feeds kept as a fallback; see "API-Football"), one module per source, offline tests, each source failing independently. The commercial plan is `playStorePlan.md`; the app is to be renamed **Telly Fixtures**.

## Principles (George's decisions – keep these)

- **No guessing (13 Oct 2026):** a channel is shown only when an official source confirms it (a broadcaster's TV guide or listings page, or the competition's own TV picks). Never infer a channel from who holds the rights. Without confirmation the event says "TV channel to be confirmed" (no pill). The one rule-based note is the Saturday 15:00 football blackout ("Not shown live on UK TV"), a broadcasting rule, not a guess.
- **Where channels come from (13 Oct 2026):** the Sky TV guide (Sky's EPG, covering every channel on Sky) is the main source. Cross-check it for missing bits against each broadcaster's own schedule pages: Sky Sports' "on Sky" pages (Sky Sports+ streams), TNT Sports' schedule (HBO Max streams), Prime Video's Champions League page (Amazon's Tuesday pick, which George considers essential) and Premier Sports' fixtures page (streaming only, so not in Sky's guide; added 20 Oct 2026). Add other broadcasters' pages the same way when needed. Darts and snooker are not only on Sky/TNT: free-to-air channels count too (see "Darts and snooker").
- **Keeping a channel (14 Oct 2026):** a channel once confirmed is kept only if the source that confirmed it failed on a later update, or the event has started (see "Keep rule").
- **Each source fails independently:** one source failing never breaks the others; the app shows a yellow banner for it.

## Architecture

- `scripts/build.mjs` (Node 24, ES modules, no dependencies) fetches every source in parallel (`Promise.allSettled`), matches events to channels and writes `data.json`: `{ generatedAt, windowDays, report, events[], golden }` (`golden`: what the daily check against the official football feeds found, for the next updates; the app ignores it). The window is UK midnight today + 9 days (`DAYS_AHEAD` = 8; the app shows 8 days).
  - Each event: `comp` (`PL`/`UCL`/`UEL`/`UECL`/`CHAMP`/`SCOT`/`WSL`/`CUPS`/`F1`/`F2`/`F3`/`MOTOGP`/`DARTS`/`GOLF`/`SNOOKER`/`CRICKET`), `kind` (`match` for football, `session` for the rest), optional `label` (cup ties: "FA Cup"/"EFL Cup"), `kickoff` (ISO UTC), `source` (where the schedule came from) and `tv` (`broadcaster`, `channels`, `alsoOn`, `confirmed`, `note`, `sources`). Sessions also have `title`, `session`, `end`, `timeTbc`, `allDay`. Football matches have `home`, `away`, `status`, `homeScore`, `awayScore`, and `checkedBy` (e.g. `uefa.com`) when an official feed corrected API-Football's kick-off or status.
  - `tv.sources` tags where a channel came from: `sky-guide`, `skysports.com`, `tntsports.co.uk`, `primevideo.com`, `premiersports.com`, `thefa.com`, `premierleague.com`, `previous-update` (kept from the last update), `listings` (the old fan site, before 13 Oct 2026; never kept).
  - `report` has one entry per source with `ok` (plus counts/errors; `wrongRegion` for Prime Video's and Premier Sports' non-UK pages), plus `footballSource` (`api-football` or `official`), `scores` (`on`/`off`) and `goldenCheck` (the daily check: per official feed `ok`, `checkedAt`, number of corrections; `changed` lists every game changed on this update). It exits 1 and keeps the old `data.json` only if every fixture source failed.
- Source modules (`scripts/sources/`), one per source family:
  - Fixtures: `apiFootball.mjs` (every football competition, the live source since 20 Oct 2026) with `teamNames.mjs` (full club names) and `goldenCheck.mjs` (the daily check against the official feeds; see "API-Football"); the official football feeds, read once a day for that check (and for the PL broadcaster ids), every update for the FA's TV picks, and in full as the fallback: `football.mjs` (PL, UCL, UEL; team-name matching `normTeam`/`teamSim`/`ALIASES`; `guideProgrammesFor` matches a match to TV-guide programmes), `efl.mjs` (Championship, League Cup), `facup.mjs`; then `motorsport.mjs` (F1, F2, F3), `motogp.mjs`, `darts.mjs`, `golf.mjs`, `snooker.mjs`, `cricket.mjs`.
  - TV listings: `skyGuide.mjs` (Sky EPG, channel IDs per sport in `SPORT_CHANNELS`, and the shared helpers that turn guide programmes into sessions: `groupSessions`, `sessionLabel`, `nameScore`, `guideTv`, `windowDates`, `isLiveCoverage`), `skyListings.mjs` (Sky Sports' pages), `tntSchedule.mjs`, `amazonPrime.mjs`, `premierSports.mjs`.
  - `footballTv.mjs`: the channel for any football match (combines the TV sources; see "Channel rules").
  - Shared helpers: `scripts/lib/util.mjs` (UK time conversion: `ukToUtc`, `ukDate`, `ukMidnight`, `londonParts`; `getJSON`/`getText`).
- **The update runs on Google Cloud in London (since 18 Oct 2026):** a Cloud Run Job `football-update` (europe-west2, Google's stock `node:24` image) started by Cloud Scheduler `football-update-trigger` every **30 minutes** (George first set 15, then chose 30; change it with `gcloud scheduler jobs update http`, see `cloud/SETUP.md`). Its start command clones `main` and runs `cloud/update.sh`, so merged code is live on the next run with nothing to deploy. The script rebuilds `data.json` and saves it to `main` with a fine-grained GitHub token (Secret Manager `github-token`, **expires about 18 Oct 2027**; the API-Football key is Secret Manager `api-football-key` → `API_FOOTBALL_KEY`); it retries a refused push up to 3 times from the newest `main`, and refuses to run outside the job unless `ALLOW_RESET=1` (it does `git reset --hard`). Commits are by "Football on TV bot" (so they are not GitHub Actions runs; look at the commits list). From a UK address Prime Video returns the UK page. Two runs within minutes of each other once got Prime Video 503 and the PL feed 429 (manual runs 2 minutes apart), but scheduled runs have all answered. `cloud/SETUP.md` is the setup guide for George.
- `.github/workflows/update.yml` has no schedule any more: it is a manual backup (Actions → Update fixtures → Run workflow). It runs from GitHub's US servers, so Prime Video and Premier Sports report `wrongRegion` and the keep rule holds their channels; GitHub has no API-Football key, so football comes from the official feeds (and the Conference League, WSL and Scottish Premiership are missing until the next London run).
- `.github/workflows/check.yml` runs on pushes to any branch except `main`: all offline tests, then a live build (not saved, official football feeds) that fails if any source didn't answer from GitHub's US servers (the expected `wrongRegion` of Prime Video and Premier Sports is only noted).
- `index.html` is the whole app (inline CSS/JS). On `*.github.io` it reads `data.json` from `raw.githubusercontent.com/<user>/<repo>/main/` (updates show within ~5 minutes), falling back to the local `data.json`. It reloads on open and when the tab becomes visible, and re-renders every minute. `?demo` loads `demo-data.json` (24 Sept 2026 week: F1, F2, darts), `?demo=2` loads `demo-data-2.json` (12–20 Oct 2026: golf, snooker, cricket) and `?demo=3` loads `preview-data.json` (real 17 Oct 2026 data plus made-up `sample: true` events for MotoGP, Specials and Rugby), pretending it's that week. Since 18 Oct 2026 this is **Design A** (3D sport icons from `sport-icons/` on tinted tiles, multi-select competition chips, a customisable **My TV** view and a day picker); `designA.md` describes it in full. Before that the app had a tab bar: the last commit with it is the parent of the commit tagged `design-a-live`.

## Channel rules

**Football (`footballTv`, every competition):** all confirmed channels from (1) live Sky-guide programmes on a football channel, on air at kick-off, naming both teams (`guideTeams` + `teamSim`; youth/women's games – "U19", "Women", "WSL" – are skipped), (2) Sky's "Football on Sky" page (`skyListingFor`: same UK date + both team names), (3) TNT's schedule (`tntProgrammesFor`: live, on air at kick-off, competition in the subtitle, both teams or one exactly) and (4) Premier Sports' fixtures page (`premierSportsFor`, Scottish Premiership only so far: competition "SPFL", both teams, coverage starting up to 2 hours before kick-off) are combined, main channel first, HBO Max last. Else, for the UCL, Amazon's own pick on Prime Video (`primePickFor`: provider "Prime", both teams in the same order, same UK date if shown). Else, for the PL, the league's own broadcaster feed gives a brand ("Sky Sports"). Else Saturday 15:00 PL/Championship/Scottish Premiership = "Not shown live on UK TV", else "TV channel to be confirmed".
- Listed: all PL, UCL, UEL, Championship and Scottish Premiership matches (Saturday 15:00 Scottish games are also "Not shown live on UK TV"); Conference League and WSL games only when a channel is confirmed (George, 20 Oct 2026; HBO Max streams count, as for the UEL). These three come from API-Football only (no official feed), so in `FOOTBALL_SOURCE=official` mode they are absent. TNT is searched for UECL (subtitle "Conference League") but not for WSL/SCOT; a WSL game is only confirmed by a women's programme ("Women"/"WSL" in the guide title or synopsis, or in Sky's page entry), and a men's game never by one. Cups tab: televised ties only – League Cup ties when in the guide or on Sky's page, FA Cup ties the FA marks "Live on …" (exact channel from the guide if listed, else the FA's wording, e.g. "BBC Sport").
- Champions/Europa League games show the broadcaster's team names (TNT's or Amazon's: "Manchester City v Paris Saint-Germain", "Atlético Madrid v Manchester United", not UEFA's "Man City v Paris", "Atleti v Man Utd").
- Team names are matched fuzzily (`normTeam`/`teamSim` and an `ALIASES` map: e.g. Atleti → Atlético Madrid, Paris → PSG, Spurs → Tottenham Hotspur). If a team fails to match a broadcaster's listing, add an alias.
- TNT's schedule lists TNT Sports 5–10 games as HBO Max streams; those channels aren't in Sky's guide.

**MotoGP (George, 20 Oct 2026: MotoGP class only, not Moto2/Moto3):** per GP weekend, Qualifying (Q1 + Q2 as one entry), Sprint and Race (`motogp.mjs`). Channel: a live MotoGP programme in the Sky guide on TNT Sports 1–4 (`SPORT_CHANNELS.motogp`; not "Moto2/3", "Rewind", "Inside Line") or TNT's schedule (titles "MotoGP" or "MotoGP | Australia"; HBO Max streams last), on air at the session start or starting up to 30 minutes after it (TNT's race coverage started 15 minutes after the feed's race time on 25 Oct 2026, after the Moto2 race). Else "TV channel to be confirmed".

**Motorsport:** practice sessions are skipped. A session's channel is confirmed when a live programme on Sky Sports F1 / Main Event / Sky Sports+ / Channel 4 covers its start and is about the same series (`seriesOf`: F1, F2 or F3; F1 Academy and Porsche Supercup are "other"). Otherwise Sky's "F1 on Sky" page (`sessionMatches`: "… GP - Qualifying 1" = Qualifying, "… GP - Race" = Race); otherwise "TV channel to be confirmed".

**Darts and snooker:** each live programme in the guide on a tournament day becomes a session. **Darts and snooker are not only on Sky/TNT (George, 20 Oct 2026):** free-to-air channels (BBC, ITV, Channel 4/5) don't start live titles with "Live" (ITV4's live European Championship was just "Darts: European Championship"), so on those channels a programme of an hour or more that doesn't look like a replay ("highlights", "review", "classic", "best of", "(20.10)"…) counts as live (`isLiveCoverage` in `skyGuide.mjs`). Sessions: simulcasts and back-to-back parts on one channel merge; before 12:00 = "Morning session", before 17:00 = "Afternoon session", otherwise "Evening session"). A televised darts day with nothing in the guide shows one "TBC" entry with "TV times to be confirmed"; snooker and golf days are only listed when the guide shows them (or, if the guide is unavailable for that day, as "TBC").

**Golf:** one entry per tournament per day ("Round 1"…, "Day 1"… for the Ryder/Solheim Cup), from the first to the last live programme that names the tournament (`nameScore`) or its tour (`tourOf`: "PGA Tour", "DP World Tour"; LPGA/LIV programmes are ignored).

**Cricket:** England matches are always listed; other internationals only when a guide programme on a cricket channel is on air at the start of play, names a team and, if it has an ordinal ("4th T20"), matches the match number. The programme must also be cricket: on Sky Sports Cricket, or with a cricket word in its text ("cricket", "ODI", "T20", "Test", "50-over", "one-day", "tri-series"; added 20 Oct 2026 after "Live Tri-Series: SL v ENG" was missed). Programmes not labelled "Live" must start close to play and name the team in the title. The main channel is one on air at the start; later ones are "also on". A Test has one entry per day ("2nd Test, Day 3"); tri-series games read "Match 2 (ODI)".

**Keep rule (`keepKnownChannels`):** every update reads the previous `data.json`. When this update finds no channel for an event that had one, the old channel is kept **only if** the source that confirmed it (`tv.sources` → report entry via `SOURCE_REPORT` in `build.mjs`) failed this time, or the event has already started (Sky's pages and Prime Video drop games once they kick off or finish; the event then stays until it leaves the window at the end of its UK day). If the source answered and simply no longer lists an event that hasn't started, the broadcaster dropped it: back to "TV channel to be confirmed". A newly confirmed channel always replaces the old one (e.g. Sky moving a game from Main Event to Premier League). Channels from the old fan site (`listings`) are never kept.

**Amazon and the UK run (stopgap ended 18 Oct 2026):** Prime Video serves each country its own page. `fetchPrimeUcl` recognises a page with no "Prime" and no "…uk" providers as `wrongRegion` (a failure: no banner, and `check.yml` only notes it). That happens on GitHub's US servers (`check.yml`, or a manual "Run workflow"), where the keep rule holds a pick found earlier. The regular update now runs from London, so the weekly "run it from a UK computer" job is no longer needed.

UK rights for 2026/27 (background only – never used to infer a channel): PL on Sky Sports and TNT Sports; UCL on TNT Sports plus Amazon Prime Video's Tuesday pick (Paramount+ takes over from 2027/28); Scottish Premiership on Sky Sports and Premier Sports; F1/F2/F3 on Sky Sports F1 (Channel 4: British GP live); MotoGP on TNT Sports; PDC darts on Sky Sports, some events on ITV; golf on Sky Sports Golf; snooker on TNT Sports, the BBC (UK Championship, Masters, World Championship) and Channel 5 (Players Championship, Tour Championship, British Open); cricket on Sky Sports and TNT Sports.

## UI decisions George has made (keep these)

- **Navigation (Design A, live since 18 Oct 2026; details in `designA.md`):** a sticky row of 3D sport icons on tinted rounded tiles (`sport-icons/`; **My TV**, Football, Motorsport, Golf, Cricket, Rugby, Darts, Snooker, Specials) that scrolls sideways. A sport with several competitions shows chips under it ("All football" + one per competition); **several chips can be on at once**, tapping a chip again switches it off, and none on = the whole sport. Darts and Snooker have one competition each, so no chips. **My TV** is the default view (the app always opens on it): it shows the competitions ticked in **Customise My TV** (a bottom sheet; saved on the phone in `localStorage` `myComps`), with "Current Selection: …" (sports only) under the two buttons. Every fixture card also shows its sport's icon under the time (so "Test" + Sky Sports+ is clearly cricket). Next to Customise is a day button ("All days", "Today", "Tomorrow" or a date): it opens a **Pick a day** sheet and narrows My TV to that day (My TV only).
- Every day of the 8-day window is listed. An empty day says what the view is about: "Nothing on TV from your picks" (My TV), the sport's message ("No televised football", "No motorsport sessions", "No televised golf", "No international cricket on TV", "No televised rugby", "No televised darts", "No televised snooker", "No big events on TV") or, with one competition chip on, its own ("No scheduled PL games", "No F1 sessions", "No televised FA Cup ties"…); two or more chips: "Nothing on TV from your selection".
- F1/F2/F3 and MotoGP: qualifying, sprint and race sessions only (no practice). Darts and snooker: TV events only, one entry per session. Golf: one entry per round on UK TV. Cricket: men's internationals between the 12 Full Members, England always, others only when on UK TV.
- Day/date headings are 16px, uppercase.

## API-Football (football fixtures and scores, live since 20 Oct 2026)

- **How the build uses it:** with `API_FOOTBALL_KEY` set, `build.mjs` takes every football competition from `apiFootball.mjs` (tests: `build(now, previous, { footballSource, showScores })`). The PL, UEFA and EFL feeds are read once a day only, for the daily check below; the PL feed's match ids (saved with the check) pair matches with the PL broadcaster feed (`plIdOf`, by teams), and the FA page (read every update) gives its "Live on" picks (`faChannelFor`; FA Cup ties are kept only when the guide or the FA page shows them; report entry `faPage`). Per-competition report entries (`premierLeague`, `championsLeague`, `europaLeague`, `efl`, `faCup`, `conferenceLeague`, `wsl`, `scottishPremiership`) come from API-Football's per-competition errors, so the app's banners work as before. Conference League and WSL games are listed only when televised (`TELEVISED_ONLY`); the Scottish Premiership in full. The footer says "api-football.com (football)" when `report.footballSource` is `api-football`.
- **Full club names (George, 19 Oct 2026):** `teamNames.mjs` maps API-Football's name of every club in the four English leagues and the Scottish Premiership to its full name ("Wolves" → "Wolverhampton Wanderers", "ST Mirren" → "St Mirren"); `home`/`away` are shown full, `homeShort`/`awayShort` keep API-Football's name for matching. A missing club keeps API-Football's name and is listed in `report.apiFootball.unknownClubs` (PL, Championship, Scottish games): add it, and recheck after each summer's promotions. WSL teams ("Arsenal W") show as "Arsenal Women", but not when the name already says so ("London City Lionesses").
- **Plan and limits:** Pro plan since 19 Oct 2026 (7,500 requests a day). Each update makes 9 requests (about 430 a day at every 30 minutes).
- **Checking it against the official feeds:** `node --env-file=.env scripts/compare-api-football.mjs [YYYY-MM-DD]` (9-day window, 9 requests; the WSL and Scottish Premiership have no official feed to compare). Results so far: 22–30 Oct 2024 (free plan) all 78 matches found, statuses and scores identical, but **the four PL games on 27 Oct 2024, the day the clocks went back, were an hour early in API-Football**; 19–27 Oct 2026 all 80 shared matches identical, including the PL games after the clocks go back on 25 Oct. Name aliases added along the way (QPR, Crvena Zvezda, RFS, Dinamo Zagreb, NEC, Hearts, Sint-Truiden). 24 Oct–1 Nov and 28 Oct–5 Nov 2026 (run 28 Oct): 142 of 143 shared matches identical, including every game after the clocks went back on 25 Oct; the exception was **Rennes v Olympiacos (UEL), which UEFA moved on 27 Oct from Thu 5 Nov 17:45 to Wed 4 Nov 15:30 (a French general strike); API-Football still had the old date two days later.** That led to the daily check.
- **The daily check against the official ("golden") feeds (George, 29 Oct 2026; `goldenCheck.mjs`):** the official feeds stay, and **win when they disagree** with API-Football. To keep the footprint on those sites small they are read **once a day**: the first update from 06:00 UK (`CHECK_HOUR`), straight away when there's no earlier check, and on the next update after a failed read. Feeds: `premierLeague` (premierleague.com; also saves the PL match ids for the broadcaster feed), `championsLeague`, `europaLeague`, `conferenceLeague` (uefa.com), `efl` (efl.com). The FA page is read every update anyway, so FA Cup kick-offs are checked against it each time (not the status: it lists every tie as upcoming). The official feed wins on the kick-off and on upcoming/postponed (live and finished stay API-Football's); a game only the official feed has is added (only within the app's window). What a check found is saved in `data.json`'s `golden` and re-applied by every update until the next check, but each correction only while API-Football still says what it said at the check (if it has changed the game since, it has newer news). A failed read keeps the last findings; no banner (API-Football's data is still shown). Official mode (`FOOTBALL_SOURCE=official`, the US backup button) makes no check but keeps `golden`. Requests: about 10 a day in total (PL 6, UEFA 3, EFL 1), down from 6 PL requests on every update before.
- **Switching back** to the official feeds, or turning scores off: `cloud/SETUP.md` → "Switching football to API-Football".

## Working conventions

- **Branches:** new features go on a branch; pushing runs `check.yml` (tests + live check from GitHub's US servers – read the result via the GitHub API, `gh` isn't installed). George reviews (preview pane or screenshots) and merges only when he says so. Small doc/fix commits George asked for can go straight to `main`. After George says to merge: merge into `main` (`git merge --no-edit`, or fast-forward), push, and delete the branch locally and on GitHub.
- **After merging to `main`:** run the five tests and push. The London job clones `main` on every run, so merged code is live within 30 minutes and nothing needs running by hand. (If a change must show at once, use Actions → Update fixtures → Run workflow; that run comes from the US, so Prime Video's UK page isn't available to it.)
- **Git:** there's no global git identity on George's PC – commit with `git -c user.name="George" -c user.email=<George's email from the session context>`; end messages with the Co-Authored-By trailer. The London bot also commits `data.json` to `main` every 30 minutes, so `git pull --rebase` before pushing to `main` – that needs the identity too (`git -c user.name=… -c user.email=… pull --rebase`), or the rebase stops half-way.
- **Update workflow:** `update.yml` checks out `main` (not the triggering commit, so a "Re-run" of an old run uses current code) and, if its push is refused because something else was saved meanwhile, rebases with `-X theirs` (its `data.json` wins) and retries up to 3 times.
- **Code:** Node 24 ES modules, no npm dependencies. One module per source; every fetch in `build.mjs`'s `Promise.allSettled`; each source gets a `report` entry with `ok`. When adding a TV source: add its `tv.sources` tag to `SOURCE_REPORT` (keep rule), a banner in `index.html` (only for the views it affects), the footer, and the data-source table above. Comments explain *why* (source quirks), matching the existing style. To add a sport or competition to the app, add it to `SPORTS` in `index.html` (icon, hue, colour, empty-day message; `soon: true` until its source exists) and see "Adding a competition later" in `designA.md`.
- **Editing files on this Windows machine:** working copies have CRLF line endings (`core.autocrlf=true`). Scripted multi-line edits must normalise `\r\n` first. Never build JavaScript source through a shell heredoc or template string containing backslashes (a `\b` once became a literal backspace character in a regex) – use the Write/Edit tools, then check for stray control characters. `.gitattributes` keeps `*.sh` files LF (they run on Linux in Google Cloud). When a script rewrites a line of a CRLF file, strip the line's trailing `\r` before appending text: a lone CR makes git treat the whole file as binary and show every line as changed (`git ls-files --eol` shows `w/-text`).
- **Requests:** some sites need browser-style headers (`Sec-Fetch-*` for europeantour.com, amazon.co.uk refuses scripts entirely). Node's `fetch` can be treated differently from `curl` – verify with Node.
